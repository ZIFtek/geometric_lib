# **Geometric lib**

Реализация базовых геометрических функций — вычисления площади и периметра разных фигур

# *square.py*

## area(a)
* вычисляет площадь квадрата
### Параметры
* float : a - длина стороны квадрата
### Возвращаемое значение
* float : площадь квадрата
### Пример вызова
```python
area(2) // 4
```

## perimeter(a)
* вычисляет периметр квадрата
### Параметры
* float : a - длина стороны квадрата
### Возвращаемое значение
* float : периметр квадрата
### Пример вызова
```python
perimeter(2) // 8
```

# *circle.py*
## area(a)
* вычисляет площадь данной окружности
### Параметры
* float : a - длина радиуса окружности
### Возвращаемое значение
* float : площадь круга
### Пример вызова
```python
area(5) // 78.53981633974483
```

## perimeter(a)
* вычисляет периметр окружности
### Параметры
* float : a - длина радиуса окружности
### Возвращаемое значение
* float : длина окружности
### Пример вызова
```python
perimeter(5) // 31.41592653589793
```

# *rectangle.py*
## area(a, b)
* вычисляет площадь прямоугольника
### Параметры
* float : a - длина первой стороны прямоугольника
* float : b - длина второй стороны прямоугольника
### Возвращаемое значение
* float : площадь прямоугольника
### Пример вызова
```python
area(3, 4) // 12
```

## perimeter(a, b)
* вычисляет периметр прямоугольника
### Параметры
* float : a - длина первой стороны прямоугольника
* float : b - длина второй стороны прямоугольника
### Возвращаемое значение
* float : периметр прямоугольника
### Пример вызова
```python
perimeter(3, 4) // 14
```

# *triangle.py*
## area(a, h)
* вычисляет площадь треугольника
### Параметры
* float : a - длина основания треугольника
* float : h - высота треугольника, проведенная к основанию
### Возвращаемое значение
* float : площадь треугольника
### Пример вызова
```python
area(6, 4) // 12.0
```

## perimeter(a, b, c)
* вычисляет периметр треугольника
### Параметры
* float : a - длина первой стороны треугольника
* float : b - длина второй стороны треугольника
* float : c - длина третьей стороны треугольника
### Возвращаемое значение
* float : периметр треугольника
### Пример вызова
```python
perimeter(3, 4, 5) // 12
```
